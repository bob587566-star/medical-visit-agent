# 健康沟通与就诊准备 Agent · 结构与边界

## 数据流

浏览器先取得随机 HttpOnly Cookie 与 CSRF Token，单独选择健康自述留存及是否允许外部处理。昵称账号注册绑定当前访客，登录、恢复和退出轮换会话；每个身份仅访问自己的健康记录。填表、对话、清单和摘要均属于该访客；后端每次用 owner + record ID 共同查找，而不是仅凭记录 ID 授权。六个页面共享同一份 Visit。资料收藏按访客隔离，旧记录缺少新增字段时使用 schema 默认值兼容加载。

七项基础字段决定采集阶段，备注可选。一次提供一个焦点问题，消息保存 followup_field 供短答对齐。对话上下文可包含待确认候选，避免重复询问；事实摘要与准备计划只使用已确认内容。候选保留原文与后端 ID，不自动写入；确认接口只使用后端保存的候选值，确认后消费候选。编辑表单使旧候选失效。用户暂停采集时停止追问，明确恢复后才继续。

观察保存原始数值、类型、单位、发生时间及备注，按带时区的实际时间排序。无时区时间按本项目 UTC+8 解释。只整理，不解释测量含义；症状观察先区分旧记录与当前报告后执行有限警示规则。计划为材料整理和沟通步骤，不是治疗方案。

对话先执行当前警示检查；紧急分支返回本机提示，自伤意念使用独立危机支持分支。有限的上下文规则只在明确承接上一条当前自述时连接症状，不能用任意旧病史触发。普通问题查询人工整理资料；问候、能力询问与采集短答分别处理。外部模型只在显式 use_model=true 时参与受限摘录，返回值必须通过结构校验且是允许发送文本中的连续片段。只有明确承接问题可将先前主诉作为检索上下文，未知地址、费用等问题不借用旧填表内容来假装命中。

knowledge/articles.json 保存 46 篇、6 类资料、来源链接、出版方与核对日期。主题过滤限制候选范围，BM25 在范围内排序；可选 HybridRetriever 固定访问本机 Ollama 生成公共资料和问题向量，融合排名。验证模型、向量数值、维数、重定向与内容变化；缓存按内容哈希和模型 digest 失效，只保存公共资料向量，不保存个人问句。离线明确显示 lexical_fallback，实际可用显示 hybrid_ollama。资料格式错误时不继续服务旧内容，不把排名当作医学置信度。本机 CLI 对规范化资料生成哈希快照，校验后回滚；模型和匿名访客没有资料修改工具。

## 目标任务执行

TaskEngine 接受三种服务器定义的目标：prepare_visit、understand_symptom、organize_timeline。默认使用本机计划；显式开启外部规划时，DeepSeek 只接收目标、已填字段名称、观察数量、公开资料 ID，并只能返回工具名称和依赖关系。Pydantic 与依赖校验要求工具白名单、步骤唯一、无环、最多八步，警示工具必须先执行，摘要与计划依赖资料读取。

每次工具调用使用独立记录快照，委托现有 Executor 实际执行。依赖失败时跳过受影响步骤，保留失败状态，不伪造完成。健康资料结论对应精确来源片段与位置；本人自述、警示规则与公共资料分别标注，不能把自述当成核实证据。无对应资料时返回缺信息状态，而不生成医学结论。

任务 POST 立即返回 202；默认本机后台最多执行两项，重启后未完成任务标记 interrupted。配置 PostgreSQL／Redis 后改用加密 SQL 快照与事务 outbox、Redis Streams 编号投递、独立 worker、租约与 fencing 提交、提交后确认消息；进程重启可继续排队任务。两种模式最多八项运行或等待，同一记录只能有一个活动任务。页面读取真实状态，不提供虚构百分比或预计完成时间。

任务结果是草稿。apply 需显式确认，并同时校验访客归属、当前警示、资料修订、知识库版本与是否已应用。保存摘要、清单、准备计划、任务标记和审计在同一事务内完成，不自动写入候选字段。记录变化时旧任务对外显示 superseded；记录升级紧急时对外显示 emergency 并禁止保存，原执行结果保留为历史。接口详见 [任务与安全流程](tasks-and-safety.md)。

## 并发与持久化

HTTPX 异步调用模型，调用期间不持有数据库提交锁。紧急提醒不排在模型请求后。每次回复提交前重新读取记录，保留其他并发提交；已删除的记录不会被慢回复重建。若资料更新，风险按最新表单重算，不能被旧结果降级；尚未解决的紧急提示不能被问候或保存表单清除。摘要生成时若表单、对话或观察变化，返回冲突让用户重试；勾选状态提交时合并保留。修改表单、确认候选和编辑时间线使旧摘要与计划失效。

默认本机仍为单进程 SQLite。独立配置可使用 PostgreSQL 池化连接、跨实例短事务锁与旧修订 CAS，Redis 原子共享限流和持久任务投递。跨两个 Store 的竞争写入、重复任务、撤回与恢复已做有限工程验证；尚无多节点故障、高可用、灾备或临床验证。摘要与清单属于准备资料，不是病历诊断。

## 防护

- 随机会话 Cookie、所有修改接口 CSRF 校验、Origin 校验、访客归属隔离。
- 64 KiB 请求限制、字段长度限制、记录／对话数量限制、普通请求频率限制。
- JSON 校验错误不回显原始输入；后台启动关闭访问日志，避免搜索词进入 URL 日志；不记录正文和密钥。
- 前端使用文本插值，来源链接限制协议；同源 CSP、禁止 iframe 嵌入、API 禁止缓存。
- 健康记录、账号昵称、CSRF、同意与任务输入采用用途及身份绑定的认证加密；必要 ID／时间／索引元数据仍明文。支持独立同意、撤回、导出、注销及 1/7/30 天留存，仍只验收虚构资料。
- 任务结果 payload 由 Fernet 加密，解密后检查 owner / task / visit 绑定；损坏内容拒绝使用。缺少已有任务所需密钥时不生成新密钥冒充旧记录。
- 任务审计仅存操作元数据，用独立派生 HMAC 密钥、链条和链头校验修改与截断。密钥保存在同一主机被 Git 忽略的数据目录；不具备外部不可篡改存证或主机管理员防护。

本机警示规则覆盖有限当前症状，并区别否定、历史、科普和不同求助等级。自伤分支先连接陪伴与专业支持，不提供危险方法；地区资源只显示核实过的适用条目。来源和保守产品边界见 [红旗依据](redflag-evidence.md)。

LocalSafetyReview 为可选本机语义升级模块，默认关闭，固定连接 localhost Ollama，不通过环境代理或重定向外发。只接受枚举分类、明确当前紧急上下文和连续原文证据；已命中的紧急规则不再等待模型。超时、未安装、结构无效、否定或历史均回退原规则，模型不能降级风险。当前只具备模拟回归，未完成真实本机语义模型和临床验证；可用状态仅代表服务连通，不能推出有效性。

规则和测试覆盖的是列出的工程行为与固定自然语言案例。有限集合通过不证明全部急症召回；没有警示不等于安全。本机工程未完成临床审核、医疗合规认证、真实患者部署或多节点高可用验证。
版本化数据库迁移、加密备份与新目标恢复、依赖审计、CI 定义、共享运行时和指标接口详见 [安全与部署](security-and-operations.md)。界面、复制和导出包含辅助整理标识，具体对外上线标识仍需按实际产品审核。
