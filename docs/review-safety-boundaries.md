# 同义表达复审的依据与产品取舍

核对日期：2026-10-12。下面是官方患者教育资料支持的求助边界及本项目的软件规则取舍，不是确诊标准，尚未经过临床专家审校。页面中的外国急救或心理热线号码不能直接用于本地产品。

## 自然表达不应改变求助边界

| 场景 | 官方依据 | 本项目应保留的差别 |
| --- | --- | --- |
| 单侧肢体无力或说话变化 | [NHS 卒中症状](https://www.nhs.uk/conditions/stroke/symptoms/) 列出单侧无力/麻木、说话含糊或表达困难；过去一天出现过相关迹象，即使已经缓解也需立即求助。页面最近审校为 2024-09-12。 | “没力气”和“无力”、“不利索”和“口齿不清”属于应支持的自述变体。不能因为漏写“突然”就忽略近期危险自述；也不能把一直存在的既往障碍或泛泛科普说成当前发作。提醒不等于助手已经诊断卒中。 |
| 嘴唇肿与呼吸异常 | [NHS 严重过敏反应](https://www.nhs.uk/conditions/anaphylaxis/) 将口唇/口腔/喉舌突然肿胀、喘不过气等列为立即求助条件。最近审校为 2023-06-21。 | “呼吸也困难”中的“也”是连接词，不应使呼吸异常不可识别。普通既往皮疹记录与当前嘴唇肿加呼吸困难不能采用同一处理。 |
| 少量痰血丝与较多咯血 | [NHS 咯血](https://www.nhs.uk/symptoms/coughing-up-blood/) 要求少量血点/血丝尽快得到专业评估；更多血或伴呼吸困难、心跳很快、胸背痛则需要立即急救。最近审校为 2024-06-13。 | “痰里带一点血丝”不能返回无警示，也不能自动等同大量出血。规则不能根据文字估算真实失血量。 |
| 成人发烧多日未改善 | [NHS 成人发热](https://www.nhs.uk/symptoms/fever-in-adults/) 建议居家处理后仍不改善或加重者尽快专业求助，未给出“单凭四天必须叫救护车”的门槛。最近审校为 2023-05-24；页面仍可访问，但其预定复审日期 2026-05-24 已过。 | “发烧四天了还没退”应触发明确的尽快专业联系提醒；单凭时长不升级为救护车。`prompt` 是此类提示的产品标签，并不表示“没事”；若同时出现意识、呼吸等危险变化，由相应规则升级。不能将儿童五天的提示门槛移植成成人确诊标准。 |
| 孕期少量出血 | [NHS 孕期阴道出血](https://www.nhs.uk/pregnancy/common-symptoms/vaginal-bleeding/) 将少量出血或点滴出血（无疼痛或只有轻微腹痛）列为尽快孕产专业联系；剧烈腹痛、肩痛、晕厥/头晕或迅速浸透卫生巾的大量出血则需急救。最近审校为 2026-02-17。 | 在明确孕期的上下文中，“有一点点出血”不能因缺少“阴道”或“见红”而漏掉。但缺少出血部位的孤立句不能自行确认为孕期阴道出血；应引导及时专业核实。 |
| 小月龄婴儿与成人资料 | [NHS 儿童发热](https://www.nhs.uk/symptoms/fever-in-children/) 给出不足三个月体温至少 38°C、三至六个月至少 39°C 的专业联系条件；难以唤醒、异常反应、呼吸变化等另有立即急救条件。最近审校为 2024-01-03。 | “婴儿”“新生儿”“小月龄婴儿”应能检索到年龄相关提醒资料，不能退回成人发热资料。仅检索年龄词不代表孩子正在发热，不自动补造测温数值或诊断。 |

## 实际第三方报告与科普问题

[NHS 抽搐急救资料](https://www.nhs.uk/symptoms/what-to-do-if-someone-has-a-seizure-fit/) 面向旁观者，不要求患者本人发消息；首次、超过常规时长、持续超过五分钟且既往时长未知、未恢复意识、重伤或发作后呼吸困难需要急救。已知癫痫、普通短暂发作、已完全恢复且有专业照护计划，不一定每次都需要救护车。

因此，“我朋友今天抽搐了，我该劝他做什么”是实际第三方报告，不能因为“朋友”二字一律当科普过滤；在恢复状态、既往照护计划未知时应保守提醒其及时联系专业帮助，不应默认安全。同理，“群里有人说他孩子正在抽搐还叫不醒”包含当前危险信息，不能机械地排除整条消息。“如果一个人抽搐该怎么处理”“书上说抽搐”“刚刷到以前的新闻视频”则是资料或假设语境，不应给当前记录写入 emergency。单靠“说/新闻/如果”关键词也不能保证区分准确，需要独立的当前事件与引用语境用例。

## 隐晦危机表达与一般准备话语

[NIMH 自杀警示迹象](https://www.nimh.nih.gov/health/publications/warning-signs-of-suicide)（2025 年修订）将空虚、绝望、觉得没有活着的理由、难以承受的痛苦、计划或告别等列为需要认真回应并尽快得到支持的变化。[NIMH 支持步骤](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide)（2024 年修订）支持不评判地倾听、直接询问安全和连接可信的人或专业人员。

产品对“活着没意思”“不想再撑下去了”等自述应采取保守危机支持，不能只识别直白的“自杀”。支持分支不宣称已判断具体意图，也不发送任何危险行为步骤。相对地，“我已经准备好了”本身不能当作自伤意念：它也可能是在说面试、表单或就诊准备。已有危机上下文中的计划完成/告别需进入支持分支；没有语境且意思不明时应先澄清，而不把普通工作准备记录升级为危机。

## 检验与限制

固定用例需要同时覆盖最小差异对、否定/既往/引用文本、实际旁观者报告，以及不同强度的求助提示。通过有限用例只能说明软件在这些例子上的行为，不能证明临床灵敏度或保证没有漏检。检索排序分和规则标签都不是疾病概率；本地语义兜底即使连通，也必须另做实际运行和偏差验收，并保持不能降级确定性红旗的约束。
