# 红旗依据与适用边界

核对日期：2026-10-12。本文记录官方患者教育页面与本项目简短中文资料之间的对应关系，供代码和用例审查使用；它不是临床指南或诊疗认证，未经过临床专家审校。下列边界不能用于独立确诊，也不能保证覆盖所有急症。

## 来源描述的升级边界

| 场景与资料 ID | 官方页面支持的求助边界 | 容易过度推断的情形 |
| --- | --- | --- |
| 自伤或自杀意念 `crisis_support` | 想死或已有计划应认真回应并立即连接支持；面临即时生命危险应急救。可信的人陪伴、倾听、减少危险物品可及。来源：[NIMH FAQ](https://www.nimh.nih.gov/health/publications/suicide-faq)、[NIMH 支持步骤](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide)。 | 不凭一句否认作安全保证；不把既往经历、科普讨论和当前意图混为同一种状态。 |
| 中毒或服药过量 `poisoning` | 怀疑有害摄入即寻求紧急医疗帮助，不等症状；物质是否有害不明确也须立即专业核实。来源：[NHS](https://www.nhs.uk/conditions/poisoning/)。 | 不用药物片数推断安全；常规服药记录不等于过量；“食物中毒”字样不能自动套用有害化学物摄入规则。 |
| 晕厥 `fainting`，复用既有资料 | 未完全恢复、无法唤醒、呼吸异常、胸痛心悸、重伤、抽搐或运动/躺卧时发作需要急救。来源：[NHS](https://www.nhs.uk/symptoms/fainting/)。 | 已完全恢复且没有上述变化仍应接受专业评估；原页面不要求每次晕厥都呼叫救护车。 |
| 抽搐 `seizure` | 首次、超过常规时长、时长未知而持续超过五分钟、连续发作未恢复、重伤或发作后呼吸困难需要急救。来源：[NHS](https://www.nhs.uk/symptoms/what-to-do-if-someone-has-a-seizure-fit/)。 | 既往已知癫痫、常规短暂发作、完全恢复且有照护计划，不一定每次急救；未知既往史不能说成已确认首次。 |
| 咯血 `severe_haemoptysis` | 超过少数血点或血丝，或伴呼吸困难、心跳很快、胸背痛需要急救；少量血丝仍须尽快专业检查。来源：[NHS](https://www.nhs.uk/symptoms/coughing-up-blood/)。 | 不把少量血丝说成已安全，也不由文字估算失血量。 |
| 伤口出血 `severe_bleeding` | 无法止血、鲜红喷血难控制、伤口很深很大、感觉或活动异常需要紧急医疗帮助。来源：[NHS](https://www.nhs.uk/conditions/cuts-and-grazes/)。 | 普通小擦伤出血不自动等同大量失血；不提供取出嵌入异物的指导。 |
| 孕期出血 `pregnancy_bleeding` | 任何孕期出血都应立即联系孕产专业人员；大量出血、剧烈腹痛、肩痛、头晕或晕厥需要急救。来源：[NHS](https://www.nhs.uk/pregnancy/common-symptoms/vaginal-bleeding/)。 | 少量出血加轻微腹痛仍须及时求助，但原页面没有把“32周”或所有腹痛一律定为呼叫救护车条件。 |
| 婴儿/儿童发热 `infant_warning` | 不足三个月且至少38°C、三至六个月且至少39°C应立即专业联系；嗜睡难醒、异常反应或喂养兴趣、首次抽搐、呼吸或肤色异常需要急救。来源：[NHS](https://www.nhs.uk/symptoms/fever-in-children/)。 | 体温和年龄门槛本身不是上述页面的救护车条件；未测温不能补造读数。 |
| 头部外伤 `head_injury` | 不能保持清醒、无法唤醒、抽搐或新的神经异常需要急救；呕吐等也需立即专业联系。来源：[NHS](https://www.nhs.uk/conditions/head-injury-and-concussion/)。 | 不把任何摔头都归为严重损伤；单次呕吐与反复呕吐并伴意识变化需区分。 |
| 呕血 `vomiting_blood` | 伴整体不适、混乱、晕厥感、呼吸快浅、冷汗苍白、腹痛或黑便需要急救；已停止且无其他表现仍须尽快专业联系。来源：[NHS](https://www.nhs.uk/symptoms/vomiting-blood/)。 | 咯血和呕血是不同的自述，分别保留对应资料，不能由助手确诊出血部位。 |

[CDC HEADS UP](https://www.cdc.gov/heads-up/signs-symptoms/index.html) 的儿童头伤资料另将反复恶心/呕吐、越来越困且难以唤醒或保持清醒等列为急诊危险征。该页面面向儿童，未作为成人头伤知识正文的单一依据。

## 产品实现与核验的解释

报告中的“刚晕倒”“刚全身抽搐两分钟”“怀孕32周，阴道出血还肚子疼”没有给出完整恢复状态、既往发作计划、出血量或疼痛程度。产品可以为这些信息缺失的近期危险自述保守显示紧急警示，但应将其称为求助提醒；不得声称来源认定这些文字必然是某种急症，也不得延迟求助来完成普通表单。

回归用例验证两个入口、否定/既往叙述、自然措辞和状态传播等软件行为。用例通过只能说明这些固定样例的行为符合预期，不能证明临床分诊能力或真实人群灵敏度。语义检索的排序能力也不是医疗风险概率；没有命中不能推出安全。

知识中不提供药物剂量、个人处方、危险行为步骤或未经地域核实的心理热线号码。NHS 页面内的英国联系号码不直接用于本项目中文求助文字。危机资源的可用性、地区匹配和服务时间需由独立资源核实流程负责；仅有官方科普链接不等于已经完成本地热线核实。
