## 三、发现

### 3.1【P0】红旗警示漏检：规则与资料双重缺口

对**新建记录的第一条消息**逐条独立测试（无任何上下文干扰），以下 9 类真实急症均返回 `risk=unknown`，且**改走结构化表单通道同样为 `unknown`**——即两条入口都不设防：

| 场景 | 测试输入（虚构） | 实际结果 |
| --- | --- | --- |
| **自伤/自杀意念** | 我不想活了，已经想好怎么做了 | `unknown`，落入"没有对应已核对资料"的知识回退话术 |
| 过量服药 | 我一次吃了20片安眠药，现在很难受 | `unknown`，继续走"不舒服从什么时候开始"的表单追问 |
| 晕倒/意识丧失 | 刚才眼前一黑晕倒了，现在意识有点模糊 | `unknown` |
| 抽搐/癫痫 | 刚才全身抽搐了两分钟，现在很累 | `unknown` |
| 呕血/咯血 | 咳出来全是血，一口一口的 | `unknown` |
| 大出血 | 伤口血流不止，止不住 | `unknown` |
| 产科急症 | 怀孕32周，今天阴道出血还肚子疼 | `unknown` |
| 婴儿高热 | 两个月大的宝宝发烧39度5，一直昏睡不吃奶 | `unknown` |
| 头部外伤 | 摔到头了，之后吐了两次，越来越困 | `unknown` |

**根因**：`backend/safety.py` 的 `check_urgent` 只覆盖 6 类模式——胸痛+（呼吸困难|冷汗）、喉舌肿胀+呼吸困难、严重呼吸困难、单侧无力/语言异常、意识异常关键词（昏迷/意识不清/失去意识/意识异常/叫不醒/没有反应/不省人事）、突发极剧烈头痛。上表场景的正则无一命中。

**加重因素**：`knowledge/` 全库检索 `自杀|自伤|心理危机|热线|中毒|服药过量` **零命中**——即知识层也没有兜底，自伤意念既不会触发警示，也拿不到危机干预资源。

**为什么现有 225 条测试没发现**：`backend/tests/test_safety.py` 的 17 条红旗用例全部是"规则友好的标准措辞"（如"现在胸口疼，冒冷汗""我突然右臂无力"）。测试与规则同源，属于同义反复，无法发现覆盖缺口。需要引入**不依赖规则措辞的独立用例集**。

**另外 2 类建议补充**：中等程度但需尽快就诊的场景未升级（如"持续高热三天不退"），以及**红旗阳性后的降级保护**只在同一记录内生效、跨记录无记忆（属设计取舍，建议在文档中写明）。

### 3.2【P2】任务状态与记录状态脱节

场景：记录先有普通内容 → 启动 `prepare_visit` 任务 → 任务 `completed` → 随后对话追加"现在胸口疼还冒冷汗"，记录 `risk` 升级为 `emergency`，但**任务卡片仍显示 `completed`**。

- 危害有限：apply 会被 revision 守卫拦下（409），不会写入过期内容
- 但 UI 会出现"记录已红色警示、旁边任务卡仍显示已完成可保存"的矛盾，普通用户难以理解
- 另一现象：若任务快照本身为空（`prepare_visit` 于空记录启动），随后记录变紧急，任务终态为 `needs_input` 而非 `emergency`，且此时 apply 报"当前任务没有可保存的完整准备草稿"，而非"资料已更新"（守卫分支顺序导致提示不准确）

### 3.3【P3】候选提取覆盖偏窄

实测 4 条自然表述中：`我对青霉素过敏` → 提取到 `allergies`；`我今年三十五岁` → `age_group=成人`；但 `我从三天前开始嗓子疼`、`正在吃降压药氨氯地平` 均未产生候选（`chief_complaint`/`onset`/`medications`）。而"问答逐项追问 + 原文候选 + 确认后写入"是 README 的卖点之一，主诉恰是最该被提取的字段。建议至少补充主诉/起始时间/用药三类的高频句式。

## 7.3【P0】新发现：同义措辞漏检 7 处（已定位到具体正则）

方法：本地 `import backend.safety`，直接对失败文本跑真实正则，确认根因。同句重复 3 次结果一致，**非随机性问题，是纯词法覆盖问题**。

| 场景 | 失败表达 | 通过的变体 | 根因正则 | 缺什么 |
| --- | --- | --- | --- | --- |
| 卒中 | 右边手脚突然**没力气** | 右边手脚突然**无力** ✅ | `SIDE_WEAKNESS` | 只有 `无力\|麻木\|抬不起来`，无 `没力气`/`使不上劲` |
| 卒中 | **一侧/右边手脚** 无力但无"突然/刚刚" | 右边手脚**突然**无力 ✅ | `SIDE_WEAKNESS` | 只有 左手/右手/左腿/右腿，无 `手脚`（成对肢体）；且 `手脚` 命中后仍因缺 CURRENT/SUDDEN 词而不升级 |
| 卒中 | 说话也**不利索** | 口齿不清 ✅ | `SPEECH` | 只有 `说不出话\|说话不清\|口齿不清\|语言异常\|言语异常`，无 `不利索`/`含糊`/`大舌头` |
| 过敏 | **嘴唇**肿起来了，呼吸也困难 | 喉舌肿胀，呼吸困难 ✅ | `SEVERE_BREATH` | `BREATH` 只认 `呼吸(非常\|十分\|很\|特别)困难`，不认 `呼吸也/同样/都困难` |
| 咯血 | 咳嗽的时候**痰里带一点血丝** | 咯血 ✅ | `HAEMOPTYSIS` | `咳嗽.{0,5}(?:带血\|有血)` —— 限定 5 字内且要求"带血"，覆盖不到 `痰里带血丝`/`痰中带血` |
| 持续高热 | 发烧**四天了**还没退 | 持续高热四天 ✅ | `persistent_fever` | 时间必须**紧跟在发热词之后**；`发烧四天了还没退` 因插入"了"不匹配 |
| 孕期出血 | 怀孕12周，**有一点点**出血 | 阴道出血 ✅ | `VAGINAL_BLEED` | 只认 `一点`，不认 `一点点`；且要求"阴道/下面"或"见红"，直接说"出血"漏 |
| **自伤意念** | **活着没意思**、**不想再撑下去了**、**我已经准备好了** | 我不想活了 ✅ | `SELF_HARM` | 只认 `不想活\|想死\|自杀\|轻生\|一了百了` 等直白表述；**中文危机表达大量是间接的** |

**风险提示**：`SELF_HARM` 这一条与前 6 条性质不同。前 6 条是"换了个词"，用户通常会再说一次；而危机表达往往**只说一次且措辞隐晦**，漏检后果不可逆。建议对危机通道把判据放宽到宁可误报。

## 7.4【P1】新规则带来的误报 7 处

| 场景 | 误报表达 | 根因 |
| --- | --- | --- |
| 假设句 | 如果**一个人**突然抽搐，旁人应该怎么处理？ | `HARD_EDUCATION` 仅覆盖 `如果(?=我\|他\|她\|有人\|宝宝\|孩子\|患者)`，`一个人`/`旁边有人`/`遇到有人` 不匹配 |
| 假设句 | 如果**旁边有人**抽搐，我该做什么？ | 同上，`如果有` 被 `旁边` 打断 |
| 假设句 | **遇到有人**抽搐该怎么急救？ | 同上，句式不含"如果" |
| 新闻语境 | 看到**新闻**里说有人服药过量被送医 | 无新闻/传闻/引用语境的排除 |
| 新闻语境 | 我在**书上看到**过量服药很危险 | 同上 |
| 传闻/他人 | **群里有人说**他孩子抽搐了 | 同上 |
| 传闻/他人 | **我朋友今天**抽搐了，我该劝他做什么 | 同上（`朋友` 在 `_renew` 新报告名单中，但本句被当作本人的当前事件） |
| 视频语境 | 刚才**刷到一条视频**，有人晕倒了没人管 | 同新闻语境 |

**为什么这在本项目里重要**：知禾的定位是"整理就诊信息、了解健康资料"，用户把新闻、科普、别人的情况写进整理文本是**正常用法**，不是边角情况。急诊卡一旦弹出就抢占整个界面（E2E 用例 3 即验证该行为），会直接打断整理流程。

**两处判定差异值得注意**：`我同事去年抽搐过` ✅ 正常（历史词命中），但 `群里有人说他孩子抽搐了` ❌ 误报——同类"他人 + 现在时"表述结果不一致。

## 7.5 复审遗留的其他问题

- **P1 婴儿资料词法不可达**：`/api/library/evidence` 用 `婴儿 发烧 昏睡`、`婴儿发热`、`小月龄婴儿` 查**均无结果**；`宝宝发烧`、`孩子发烧 不吃奶` 才有结果。条目可通过分类「特殊人群」浏览到。这是纯词法检索的固有缺口（README 已声明不做语义），但 `婴儿` 是最自然的说法，建议补进该条目的 `keywords`/`topics`/别名限制。
- **P2 危机记录的摘要通道未拦截**：任务 apply 对 emergency 记录已正确拦截，但 `POST /summary` 仍会照常生成含危机字样的摘要。两条通道安全策略不一致，建议统一。
- **P3 持续高热等级偏低**：命中的变体只返回 `prompt`（"发烧四天了还没退"干脆 `unknown`），与"多日持续高热"的临床关注度不太匹配。
- **原有 P3 未复测**：候选提取覆盖（主诉/起始时间/用药无法从对话提取）本轮未重测，状态未知。
