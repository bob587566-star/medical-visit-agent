## 实际公开 HTTPS 接口

使用独立 Cookie、随机虚构账号与虚构健康自述，50 次请求全部符合预期；其中正常响应和预期的 401／403／404／409 均作相应断言。共 547 项断言，多数是各请求的通用协议和安全头检查，不能当作 547 个独立业务场景。

- 昵称注册、退出、独立登录与恢复本人记录；清除 Cookie 后仍可通过账号登录读取资料。
- 明确显示云端存储，未同意时拒绝建立记录；外部模型同意与调用保持关闭。
- 保存虚构自述、聊天、资料检索、摘要和准备计划；诊断及药物剂量请求得到受限回复。
- 目标任务在请求内完成，结果经手动确认保存，重复保存遵守幂等约束。
- 陌生访客不能读取本人记录或任务，跨站来源被拒绝；Cookie 与响应安全头符合约定。
- 本人导出、删除单条、清空、撤回同意、删除账号及删除后拒绝登录。验收创建的账号和记录已清理。

## 独立 Edge 浏览器

使用全新 headless Edge 上下文，未读取用户浏览器配置或登录 Cookie。根页面与工作台可用，隐私页面显示云端存储，两项同意初始均未勾选；选择 1 天留存后正常进入工作台，资料库显示 46 条。

隐私页、工作台、资料库在 390／320 像素宽度下共六项布局检查均无横向溢出。页面异常为 0，失败静态资源为 0。该测试访客已撤回同意，并核对本人记录为空。截图及详细机器报告保存在本机被 Git 忽略的 `data/vercel-ui-*` 中。

## 配置与边界

使用专用云端数据库、TLS Redis 和新生成的云端加密密钥，不上传本机 SQLite、会话、账号、健康记录、密钥文件或备份。上传预检只包含 67 个应用源文件与配置。Neon 和 Redis 选择免费套餐，Redis 创建请求显式关闭自动升级。

验收连接经过当前机器已有的 loopback HTTP 代理，HTTPS 证书验证保持开启；本机直连遇到代理路由 TLS 中断，不能据此声称中国大陆所有网络均可直连。

云端当前使用规则与主题／词法资料检索，不连接本机 Ollama，也未配置外部 DeepSeek Key。请求中断后，本人重新打开任务可继续处理；没有无人访问时持续运行的独立 worker。此地址为工程演示，未完成临床审校或医疗资质认证，不作为真实患者诊疗服务。
