| 婴儿资料 | 婴儿/婴儿发热/小月龄婴儿/新生儿别名能检索 infant_warning，儿童相关发热不借用成人资料；仍 46 条 | 独立检索与实际 library/evidence 两端点 |

## 尚未验证的边界

只读探测本机 11434/api/tags 仍连接拒绝，运行配置为 rules_only。真实 Ollama 语义端到端验收未完成；没有启动被自动审批拒绝的操作，也没有改用外部医疗 API 替代。新增的 4 项 API 语义集成通过模拟本机传输验证接线、引用/否定保护、规则红警优先与摘要阻断，不冒充真实模型 E2E。

这里的固定集通过不代表临床灵敏度、覆盖所有自然说法、无其他缺陷或医疗审核。当前仍只适合虚构演示，原访视/聊天库未加密，尚无临床专家审校；未命中不能推断安全。
