## 相关改动与限制

已增加三类目标任务、受限依赖计划、真实工具执行、任务异步状态、原文证据账本和显式保存。资料库可快照与回滚，任务保存检查资料与知识版本。任务 payload 使用 Fernet，审计为本机 HMAC 链；原访视、聊天与会话库仍未加密，不是患者生产系统。

实际 DeepSeek 规划首次返回空正文，按无效计划回退。修正请求为关闭思考模式并补充受限 JSON 图示例后，重新验收获得有效计划，校验后调用本机工具完成目标；外部请求仅包含目标、已填字段名称、观察数量、公开资料 ID，不包含自述正文。参考服务商 [思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 与 [JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。真实结果在 task_http.json/md；单次有效返回不代表服务商永远输出有效计划，无效输出仍回退。

当前真实检索是 lexical_fallback。可选本机语义复核默认关闭，模拟测试验证了不降级、否定/历史/假设、超时和非法结果等边界，尚无真实语义模型验收。启动 Ollama 被自动审批拒绝，工具仅返回 `blocked by policy`，未给具体原因；没有改用外部医疗语义 API 绕过。

知识和警示依据见 `docs/redflag-evidence.md`；尚未经临床专家审校。固定虚构集合通过不代表临床召回率、覆盖所有急症、医疗合规认证或没有其他缺陷。未命中警示不代表安全。
