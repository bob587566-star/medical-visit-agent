# 知禾健康沟通工作台 V2 · 本机验收

2026-10-12，Windows 本机，入口 http://127.0.0.1:8270/，版本 2.0.0。

## 实际扩展

- 三个入口扩展为六区：总览、信息准备、问答、变化时间线、健康资料库、摘要与计划。
- 以七项基础信息计算填写进度，备注可选。对话逐项追问，候选保留自述原文，确认后才保存；历史候选不可重复确认。
- 时间线保存症状、体温、血压、血糖或备注，带时间与单位；按实际时区时间排序，进入摘要与 TXT，不解释测量含义。
- 资料由 13 篇扩展为 37 篇、6 分类，新增官方来源核对记录；支持分类、查阅、收藏、取消收藏及真实检索状态。
- 准备计划依据已确认信息和观察生成，含材料、安排核实与沟通问题；修改原始资料后旧摘要／计划失效。
- 支持本机 Ollama Embedding、BM25 与向量排名融合、公共资料哈希缓存；本机服务当前不可用，明确显示 lexical_fallback。

## 检查发现并修复

1. 确认当前字段后仍沿用旧助手问题，导致短答漏抽或归入错误字段；现在跳过已确认的字段。
2. 保存普通表单会清掉对话里的尚未解决紧急提示；现已保留，普通问候也不继续采集。
3. 慢模型返回会降级更新后的儿童／重度提示；提交时依据最新资料重算，并保持消息与记录一致。
4. 候选最大长度与 schema 不一致；现统一限制，避免校验异常。
5. Windows PowerShell 5 无 BOM 中文脚本解析失败；脚本采用 UTF-8 BOM，启停实测通过。
6. 开发服务器实际使用 5174，来源名单却仍为 5173；已同步，并验证外部来源继续拒绝。
7. 后台关闭 HTTP 访问日志，避免健康搜索词写入 URL 日志。
